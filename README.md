### About Me

Frontend-Focused Software Developer with experience building responsive, accessible web and mobile applications using JavaScript, TypeScript, React, and Next.js. Comfortable managing projects end-to-end, from translating Figma designs into production interfaces to deployment via Vite/Vercel and domain configuration.

Currently expanding into AI agent development and applied AI tooling, with working knowledge of Azure cloud infrastructure and databases. Frontend remains my primary focus, with growing interest in backend development.

Background in digital marketing — social media strategy, content creation, and website optimization — maintained on a volunteer basis. This experience informs a practical understanding of how design decisions affect user engagement, beyond visual design alone.

Committed to accessibility (WCAG), clean code, and sustainable, maintainable software.
